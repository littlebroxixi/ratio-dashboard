# 指数比值趋势偏离看板

用于监控以下三组指数比值：

- IC / IF：中证500 / 沪深300
- IM / IC：中证1000 / 中证500
- IM / IF：中证1000 / 沪深300

## 当前模型

看板支持1年、3年、5年、7年、10年、15年、20年和全局窗口。详情页在每个已选窗口内左右并列展示两种口径，
并使用完全相同的样本区间和纵轴范围：

- 左侧：固定OLS趋势线与残差标准差通道
- 右侧：固定算术平均值与普通样本标准差通道

每个窗口截取截至当前的`年数 × 252`个交易日，并在该区间内只计算一次中枢和波动率。
窗口按钮高亮代表展示、灰色代表隐藏，默认展示1年、3年、5年和7年；历史不足的年份按钮不会显示。
全局窗口始终可用，并使用观察日期以前能够取得的全部历史数据。

详情页提供“观察日期（截至日）”。选择历史日期后，系统先删除该日期之后的全部行情，
再构建当时数据长度所支持的全部窗口；若选择周末或节假日，则自动回退到此前最近一个交易日。
因此查看历史日期时不会使用未来数据。日期栏右侧提供各年份窗口的显示开关。

- 趋势中枢：当前日期在固定OLS趋势线上的对应值
- 残差：当天实际比值减去趋势中枢
- 残差标准差：`sqrt(SSE / (N - 2))`
- Z-Score：`残差 / 残差标准差`
- 多周期确认：至少两个窗口在同一方向超过 `±2σ`

平均值方法：

- 中枢：固定窗口内比值的算术平均值
- 普通样本标准差：`sqrt(sum((x - mean)^2) / (N - 1))`
- Z-Score：`(当前比值 - 平均值) / 普通样本标准差`

固定窗口图用于回答“在所选观察日期，当时处于所选年份样本里的什么位置”。
图中更早日期的Z仍使用了该窗口截至日以内的整段信息，不能作为更早日期当天已经可知的交易信号。

首页继续使用OLS多周期确认规则；平均值方法作为详情页右侧的对照模型，不与OLS确认数混合。
