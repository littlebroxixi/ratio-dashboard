# 指数比值趋势偏离看板

首页使用统一的三列卡片网格，BTC / 黄金位于第二行第一张卡片，与指数卡片等宽、整卡可点击。卡片共用比值、趋势缩略图、3/5/7 年 OLS Z 与年化斜率、状态及方向提示组件。所需模型、日线和研究汇总全部在本仓库内，可直接部署到 Streamlit Cloud。

## BTC / 黄金模块

- 日线底表：`data/btc_gold_daily.csv`，BTCUSDm 收盘 ÷ XAUUSDm 收盘；2018-02-09 至 2026-10-27，共 2,705 条共同日期。保留周日记录，不补值、不插值。数据是 MT5 导出快照，首页刷新不会追加新日线。
- 模型：`btc_gold.py` 将日历模型适配到共用的卡片及详情数据结构；1/3/5/7 年窗口按实际日历截取，另有全局样本。OLS 使用共同日线观测序号，残差标准差分母 N-2；均值法标准差分母 N-1。展示的年化斜率按样本真实跨度换算，不改变原拟合和 Z 值。
- 定位：与指数共用 `streamlit_app.py` 的 `render_detail`，包括返回首页、观察日期、回到最新、年份按钮、成组的 OLS／均值 Z 指标以及统一配色的并排通道图。历史定位只使用观察日及以前的数据。详情底部仅保留「计算口径与使用说明」，不展示收益、收敛及日线折叠区。
- 研究结果：`data/btc_gold_research.json`；固定持有 1—6 个日历月及 12 个月内的 Z 值收敛统计。结果截至 2026-10-27，不随定位页的日期选择改变；加载时核对底表 SHA-256，避免新旧版本混用。
- 入场：逐日重估信号，首次向外进入同一偏离区间；回到同侧 1σ 或经过 12 个月后重新允许入场。固定持有统计采用完整 6 个月观察期的共同事件队列；收敛统计采用完整 12 个月观察期且下一日开盘可用的队列。
- 收益：收盘信号后的下一共同日开盘入场，固定期限于目标日或此后首个共同日收盘退出；Z 触发退出使用下一共同日开盘。原方法的信号日收盘收益另列对照。
- 每腿入场名义金额 100,000 美元、数量固定；收益分母 200,000 美元，为未扣点差、滑点、佣金与隔夜费的毛收益参考，并非保证金收益率。日线标签不能证明两腿报价完全同步，日线不利波动不代表日内最大风险。
- 同一行情可能贡献多个窗口／区间事件，不能把汇总事件当作独立交易复利；无样本保留空值。

指数原有窗口和数据源口径保持不变。后续更新 BTC 数据时，应同步重新生成研究汇总及其底表校验值。

用于监控以下三组指数比值：

- IC / IF：中证500 / 沪深300
- IM / IC：中证1000 / 中证500
- IM / IF：中证1000 / 沪深300

## 当前模型

看板支持1年、3年、5年、7年、10年、15年、20年和全局窗口。详情页在每个已选窗口内左右并列展示两种口径，
并使用完全相同的样本区间和纵轴范围：

- 左侧：固定OLS趋势线与残差标准差通道
- 右侧：固定算术平均值与普通样本标准差通道

每个窗口截取截至当前的`年数 × 252`个交易日，并在该区间内只计算一次中枢和波动率。
窗口按钮高亮代表展示、灰色代表隐藏，默认展示1年、3年、5年和7年；历史不足的年份按钮不会显示。
全局窗口始终可用，并使用观察日期以前能够取得的全部历史数据。

详情页提供“观察日期（截至日）”。选择历史日期后，系统先删除该日期之后的全部行情，
再构建当时数据长度所支持的全部窗口；若选择周末或节假日，则自动回退到此前最近一个交易日。
因此查看历史日期时不会使用未来数据。日期栏右侧提供各年份窗口的显示开关。

- 趋势中枢：当前日期在固定OLS趋势线上的对应值
- 残差：当天实际比值减去趋势中枢
- 残差标准差：`sqrt(SSE / (N - 2))`
- Z-Score：`残差 / 残差标准差`
- 多周期确认：至少两个窗口在同一方向超过 `±2σ`

平均值方法：

- 中枢：固定窗口内比值的算术平均值
- 普通样本标准差：`sqrt(sum((x - mean)^2) / (N - 1))`
- Z-Score：`(当前比值 - 平均值) / 普通样本标准差`

固定窗口图用于回答“在所选观察日期，当时处于所选年份样本里的什么位置”。
图中更早日期的Z仍使用了该窗口截至日以内的整段信息，不能作为更早日期当天已经可知的交易信号。

首页继续使用OLS多周期确认规则；平均值方法作为详情页右侧的对照模型，不与OLS确认数混合。

## 数据来源

- 长期历史底表：用户从同花顺 iFinD 下载的中证1000、中证500和沪深300日线点位，已剔除4条非交易日记录。
- 每日正式收盘：优先通过同花顺 Quant API 追加，并覆盖最近30天重叠区间以保持精度。
- AkShare：仅用于交叉校验、同花顺暂时不可用时补齐缺口，以及盘中参考；不会覆盖已有同花顺数据。
- 所有指数比值均在网站内用原始点位重新计算，不使用预先四舍五入的比值列。

部署时在 Streamlit Secrets 中配置：

```toml
IFIND_REFRESH_TOKEN = "你的同花顺 refresh_token"
```

真实令牌不得写入代码库。当前令牌到期前需要在 Streamlit Secrets 中替换。
