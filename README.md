# 指数比值趋势偏离看板

用于监控以下三组指数比值：

- IC / IF：中证500 / 沪深300
- IM / IC：中证1000 / 中证500
- IM / IF：中证1000 / 沪深300

## 当前模型

看板同时展示3年、5年、7年三个固定最小二乘窗口。每个窗口截取截至当前的
`年数 × 252`个交易日，并在该区间内只拟合一次趋势线。

- 趋势中枢：当前日期在固定OLS趋势线上的对应值
- 残差：当天实际比值减去趋势中枢
- 残差标准差：`sqrt(SSE / (N - 2))`
- Z-Score：`残差 / 残差标准差`
- 多周期确认：至少两个窗口在同一方向超过 `±2σ`

固定窗口图用于回答“今天在最近3年、5年或7年的样本里处于什么位置”。图中旧日期的Z使用了
整个固定区间的信息，不能作为旧日期当时已经可知的历史交易信号。

旧版的全局普通均值、固定标准差、建仓/重仓/All-in阈值和基于旧Z值的收益效率结论已移除，避免不同统计口径混用。
